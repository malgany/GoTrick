# GoTrick 0.1.2 — Windows e Ubuntu 24.04 (preview)

Esta versão adiciona uma distribuição completa para **Ubuntu 24.04 x64**, junto do instalador **Windows x64**.

## Qual arquivo baixar

| Sistema | Download |
|---|---|
| Windows x64 | `GoTrick-0.1.2-windows-x64-setup.exe` |
| Ubuntu 24.04 x64 | `GoTrick-0.1.2-ubuntu-24.04-x64.tar.gz` |

Os arquivos com `sources` no nome e os downloads automáticos **Source code** são código-fonte, não instaladores. Os dois pacotes incluem JBR, gopls e Delve nativos do sistema. O SDK Go continua separado e pode ser selecionado ou baixado em **GoTrick → Configure Go SDK…**.

## Instalar no Ubuntu

```bash
mkdir -p ~/Apps
tar -xzf ~/Downloads/GoTrick-0.1.2-ubuntu-24.04-x64.tar.gz -C ~/Apps
cd ~/Apps/GoTrick-0.1.2
./install.sh
./bin/gotrick
```

Use uma sessão gráfica Ubuntu Desktop 24.04 em computador x86_64 (Intel/AMD 64 bits). Python 3 e bibliotecas gráficas são necessários; Java não precisa ser instalado separadamente. Consulte o README para dependências em sistemas mínimos. O script registra o menu de aplicativos por usuário. Mantenha a pasta extraída no lugar; `uninstall.sh` remove seu atalho e preserva projetos e preferências.

No Windows, feche o GoTrick e execute o instalador. O instalador ainda não possui assinatura digital de publicação.

## Alterações

- Novo pacote Linux com inicializador, identidade GoTrick, atalho e dados separados conforme os diretórios XDG.
- Download de SDK oficial para Linux x64, com verificação SHA-256, extração de tar.gz e preservação das permissões executáveis.
- Descoberta de SDK respeita maiúsculas/minúsculas e evita duplicar caminhos equivalentes no Linux.
- Bootstrap, empacotamento e validação reproduzíveis para os dois sistemas; uma única tag anotada identifica a revisão de ambos.

## Validação e limites

Resultados do plugin, inicializadores e serviços Go/LSP/DAP são conferidos nos dois sistemas. Os assets `VALIDATION-windows-x64.json` e `VALIDATION-ubuntu-24.04-x64.json` registram os pacotes efetivamente testados e seus hashes.

A validação Linux foi preparada em Ubuntu 24.04 sob WSL2. A aceitação completa da interface gráfica em Ubuntu Desktop físico, incluindo diferenças entre Wayland e X11, fica pendente do teste de uso. Esta release continua experimental. ARM64, Ubuntu 22.04 e outras distribuições não foram validados. Attach/depuração remota e árvore estruturada de resultados de testes ainda não estão implementados.
