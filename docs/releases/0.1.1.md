# GoTrick 0.1.1 — Windows preview

Correção da inicialização da análise Go em projetos sem SDK configurado e dos atalhos usados ao executar o GoTrick pelo código-fonte.

## Download e instalação

Baixe **GoTrick-0.1.1-windows-x64-setup.exe** nos Assets. Requer Windows x64. Feche o GoTrick antes de atualizar. A instalação é por usuário e preserva projetos e preferências. O instalador desta prévia não possui assinatura digital de publicação.

O SDK Go continua separado: use **GoTrick → Configure Go SDK…** para selecionar ou baixar uma versão oficial, com verificação SHA-256. JBR, gopls e Delve acompanham a IDE.

## Correções

- A análise aguarda um SDK Go válido, evitando a sequência de erros **no views** do gopls quando nenhum SDK está disponível.
- Um aviso por projeto orienta a configuração do SDK. Ao alterar a seleção, a análise reinicia automaticamente, respeitando a desativação explícita do servidor pelo usuário.
- Na execução pelo código-fonte, abrir sem indicar uma pasta permite restaurar o último projeto. O atalho fixado usa o inicializador nativo com as mesmas configurações, corrigindo a abertura sem projeto e o agrupamento do ícone nesse ambiente.
- O processo de publicação passa a incluir orientação para commit e push, modelo de notas e registro automático da revisão nos assets.

## Validação e limites

A correção passou em 59 testes automatizados, incluindo gopls real e recuperação após selecionar um SDK, e em 11 verificações dos serviços Go/LSP/DAP. O projeto de exemplo foi reaberto na máquina de desenvolvimento sem novos registros de **no views**. Os resultados do instalador desta versão são registrados no asset **VALIDATION.json** após o teste do pacote.

Esta é uma prévia experimental. A captura visual da IDE não ficou disponível; todos os fluxos visuais e uma máquina/VM limpa continuam pendentes. Não há equivalência completa ao GoLand nem suporte a plugins que exigem APIs proprietárias. Os resultados de testes usam console textual; attach e depuração remota não estão implementados. Ubuntu continua planejado, sem pacote publicado.

## Componentes e integridade

IntelliJ Community 2025.2.6.3 (IC-252.28539.97), JBR 21.0.9+1-b1038.78, LSP4IJ 0.21.0, gopls v0.24.0 e Delve v1.27.2. Código próprio sob Apache-2.0; avisos e licenças dos componentes permanecem na distribuição.

Confira **SHA256SUMS.txt** antes de instalar. **release-manifest.json** identifica a revisão empacotada; **VALIDATION.json** identifica o instalador testado. Os fontes correspondentes do JBR e LSP4IJ acompanham a release e não são necessários para executar a IDE.
